Tester une application web ‘Site de Réservation de vol, Site d’achat en ligne, …’:
Part1
 Création d’un projet sous JIRA contient le nom de l’application
 Création des users stories
 Création d’un plan de test sous Xray et assigner ces tests a ces users stories
 Création d’un plan d’exécution et exécuter votre plan de test
Part2
 Création des tests automatiques pour cette application  via un outil a votre choix selenium et cypress avec comparison 
 Executer/Lancer la suite de tests automatiques et analyser les résultats
 mettre votre projet sur Git et lancer la site de tests via Jenkins
